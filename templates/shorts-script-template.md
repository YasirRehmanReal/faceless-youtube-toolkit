# Shorts Script Template (45–60 seconds)

≈110–150 spoken words total. One idea, one emotion, one payoff. Write each line as it will be spoken.

**Topic:** …
**Emotion (pick one):** ☐ heartbreak ☐ gratitude ☐ surprise ☐ pride ☐ regret ☐ hope
**The payoff line (write this FIRST):** …

## The script
| Beat | Time | Spoken line | On-screen |
|---|---|---|---|
| HOOK | 0–3s | … (the strongest line of the story — never a greeting) | Big caption of the hook |
| Setup | 3–12s | Who, where — the minimum the payoff needs | Scene 1 |
| Beat 1 | 12–25s | The problem / the kindness / the mistake | Scene 2 |
| Beat 2 | 25–40s | The turn — things get worse, or the hidden truth appears | Scene 3 |
| PAYOFF | 40–52s | The line you wrote first. Deliver it slowly. | Closest visual, music dips |
| CTA | 52–60s | ONE comment question people will actually answer | Question on screen |

## Shorts rules
- First frame = a face/emotion or a striking visual, never a logo or a title card
- Captions on, always — most Shorts are watched on mute first
- A visual change every 2–4 seconds
- End on the emotion, not on "subscribe!" — the comment question *is* the CTA
- Loop check: does the last line connect back to the first? Loopable Shorts get rewatched, and rewatches are rocket fuel

## Self-check
- [ ] Read aloud with a timer: 45–60s?
- [ ] Hook understandable with the sound OFF (captions)?
- [ ] One emotion only — no topic-hopping?
- [ ] The comment question is answerable in under 5 words?
